Quick one: what does a vector database actually store?

A vector database stores embeddings: fixed-length arrays of numbers that represent the meaning of a piece of text, an image, or any other content. Each stored point pairs the vector itself with a payload of metadata, and queries work by similarity: the database finds the stored vectors closest to the query vector rather than matching exact keywords.
