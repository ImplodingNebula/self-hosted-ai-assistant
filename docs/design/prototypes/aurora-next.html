Quick one: what does a vector database actually store?
+1s

A vector database stores embeddings: fixed-length arrays of numbers that represent the meaning of a piece of text, an image, or any other content. Each stored point pairs the vector with a payload of metadata, and a query finds the stored vectors closest to the query vector instead of matching exact keywords.

  • Snapshot first. Take a full collection snapshot and verify it restores on the new host before touching the old one.1
  • Pin the embedder. Vectors are only comparable if the new host serves the same embedding model and version; a silent model change strands every stored vector.2
  • Re-point by config, not by code. The connection URL lives in .env, so the cutover should be one variable change:
